## 你选择什么

| 参数 | 区间 | 作用 |
|---|---|---|
| `trader` | 任意地址 | 账户开给谁。填自己的地址，就是自费账户 |
| `accountSize` | \$10-\$20,000 | 本金 `A` |
| `drawdownBps` | 500–2500（5%–25%） | 追踪回撤参数 `D`，决定准备金 `R` |
| `builderPoolBps` | 1000–7000（10%–70%） | 普通利润中出资方的分成比例 |
| `targetProfit` | ≥ 0 | 以 USDC 计价的目标利润金额；`0` 表示不启用目标 |
| `feeBps` | 200 / 400 / 800 | 出资方路径必须传入 **200**。自费选择期限 |
| `proposedReferrer` | 可选 | 绑定调用方 |

日回撤不是可选参数：出资方账户启用，自费账户不启用。

## 激活时支付的金额

公式中的 `D` 和 `F` 以基点表示：100 bps = 1%。下文金额已换算为美元。

```
R = floor(A × D / 10_000)     // backer-owned reserve
P = ceil(A × F / 10_000)      // premium, a share of A, not of R
activationCharge = R + P
```

提高 `D` 会增加准备金，但不会提高溢价。准备金用于承担本金损失，只有未消耗的部分会退还；没收性关闭时若 vault 有债务，其中一部分用于偿还，见下文“Vault 债务偿还”。

| 路径 | `F` | 期限 |
|---|---|---|
| 出资方账户 | 200（2%） | 30 天，可续期订阅 |
| 自费 T1 | 200（2%） | 预付 1 天 |
| 自费 T2 | 400（4%） | 预付 7 天 |
| 自费 T3 | 800（8%） | 预付 30 天 |

```
protocolPremium = floor(P × 50%)
vaultPremium    = P − protocolPremium
```

你以 USDC 支付 `R + P`，本金 `A` 由 vault 拨付。

示例：`A = $1,000`、`D = 1000`（10%）、`F = 200`（2%）时，`R = $100`、`P = $20`，激活时共支付 `$120`。其中 `$100` 为准备金，`$20` 为溢价，由 vault 与协议各分得 `$10`。vault 向账户拨付 `$1,000` 本金。

## 拨付上限

直接激活不要求持有 vault 份额，但受以下拨付上限约束：

| 上限 | 默认 | 含义 |
|---|---|---|
| 最大利用率 | NAV 的 80% | 已拨付给存续账户的本金占 NAV 的比例 |
| 单账户上限 | NAV 的 10%，封顶 \$20k | 单个 `A` |

在 NAV 达到启动门槛（默认 \$100）之前，任何账户都不能激活。低于该值时仍可存款。

## 订阅

```
subscriptionFee = ceil_to_1_USDC(A × 1.5%)
```

按 50/50 分给 vault 与协议，你不从中分成。

订阅费从账户的 Core 权益中扣除，而不是从你的钱包。续期要求利润至少覆盖费用，且支付后权益不低于追踪或日下限。

## 利润与关闭

每次利润提取和每次普通关闭，你都按激活时选定的分成比例获得利润。没收性关闭（回撤触发或交易员请求）时，账户中剩余的利润由你和协议**各得一半**。未使用的 `R` 仍退还给你；vault 有债务时，没收性关闭会先从中留下一部分偿还，见下文“Vault 债务偿还”。提取与关闭的完整规则见[利润与派付](/zh/funded/payouts)。

## Vault 债务偿还

若其他账户超出准备金的亏损让 vault 有债务，那么当你的账户因没收性关闭（回撤触发或交易员请求）而结束时，vault 会从你未使用的 `R` 中留下一部分，而不是退还。这是不得已的措施，而且有上限：最多是已接受峰值利润（超过 `A` 的部分）每 1 美元中的 30 美分，并且不超过债务或你未使用的准备金。偿还是自动的，从你的退款中扣除，因此你在单个账户上的损失仍不超过 `R + P`。激活时无法停用该偿还，其他关闭原因也不偿还。示例见[收益与风险](/zh/vault/yield)。
