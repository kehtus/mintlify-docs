## Custody

Proportion is non-custodial: funds are held by the contracts, not by the team. Each payout is credited to a fixed address and can be claimed without anyone's approval, even while the vault is paused. The risk engine and the exchange proxy trade through Hyperliquid API wallets, which cannot withdraw or transfer funds.

## Audit

Proportion's smart contracts have had an independent security audit. It covers the code revision and scope named in the report, not later changes. The code is also checked by manual review and automated analysis.

**Audit report:** [View the security audit report](https://beosin.com/audits/Proportion_202603161420.pdf)

## Contract changes

Changes to the contracts go through a multisig wallet and a 72-hour timelock: a change is queued onchain first and takes effect only after the delay, so anyone can see it before it applies. Protective actions take effect immediately.

| Waits 72 hours in the timelock | Takes effect immediately |
| --- | --- |
| Upgrades of the two vaults, ownership changes, changes to the factory and integrations, risk settings, adding markets and raising leverage caps, unpausing | Pausing the vault, cancelling a queued change, stopping challenge purchases, removing a market, lowering leverage caps |

The risk engine's relayer cannot upgrade the contracts, change parameters or unpause.
