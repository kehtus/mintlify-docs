> 真实的 Hyperliquid 成交。规则和派付写在合约里，不在公司后台。

交易员在链上 funded 账户中使用分配给自己的资本交易，订单进入真实的 Hyperliquid 订单簿。账户规模、回撤参数、利润分成和目标利润在激活时固定；市场名单与杠杆上限以协议的当前设置为准。合约根据 HyperCore 权益检查风险规则。

<Tip>
合约已经入账的利润不属于公司。公司不能在协议规则之外随意拒绝这笔派付。
</Tip>

## 如何获得账户

由出资方开户，或交易员自己出资开户（自费）。出资方在协议之外怎样筛选交易员（考核、自己的平台），由出资方自己决定，与协议无关。

账户绑定交易员的 HyperEVM 地址。

| | 出资方账户 | 自费 |
|---|---|---|
| 谁付 `R + P` | 出资方 | 交易员 |
| 本金 `A` | 来自 vault | 来自 vault |
| 日回撤 | 开 | 关 |
| 时间 | 30 天订阅，可续期 | 预付 1 / 7 / 30 天 |
| 普通利润 | 按激活时的分成比例 | 同一比例，两部分都归交易员 |

两种模式使用相同的追踪下限。

```
激活 → Active → 交易
              → 提取利润（可选）
              → 关闭 → 结算 → 领取
```

账户关闭后，合约按激活时固定的条款结算，并把应付款项记入领取账本。
