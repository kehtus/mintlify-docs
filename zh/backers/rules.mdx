---
title: "协议规则"
description: "协议在链上强制执行什么，以及出资方不能放宽什么"
---

你在允许区间内选择参数。账户激活后，出资方和交易员不能修改其回撤参数、利润分成或结算规则；当前市场白名单仍可由协议更新。

| 规则 | 取值 |
|---|---|
| 普通利润 | `builderPoolBps` 给出资方，剩余给交易员。Vault 和协议拿 0 |
| 被没收的盈余 | 出资方获得 50%，协议获得余数（包括舍入尾差）。Vault 和 LP 拿 0 |
| 利润锁定 | 已接受峰值利润的 30%，生命周期与日下限 |
| 提取 | 未设 TARGET 时，利润至少 $1，且满足 3 个盈利 checkpoint 日（≥ 0.70%）或利润 ≥ `A` 的 1.5%；还须满足持仓、期限和风险检查 |
| Checkpoint | 1 天 |
| 出资期限 | 30 天订阅 |
| 日回撤 | 出资方账户开，自费账户关 |
| 谁可以出资 | 任何有 `R + P` 的人 |
| 市场 | 当前 MainVault 白名单。编辑不会关闭账户 |

## 追踪下限

```
A = $1,000, D = 10%, accepted peak = $1,200
baseFloor  = $900
profitLock = $60
trailing   = $960
```

日内峰值只有在通过 1% 门槛后才会更新。Checkpoint 接受任何更高的生命周期峰值。利润领取完成后，峰值重置为 `A`；追踪下限回到 `A − R`，并非 `A`。

## 日回撤

不是激活时传入的开关。出资方账户：开，为 `D` 的一半。自费：关。

同一示例，日初 `$1,000`，日峰值 `$1,200` → 日下限 `$1,010`。有效下限取二者较大值。

## TARGET

`targetProfit` 是链上记录的绝对利润金额，零表示不启用目标。只要设置了非零 TARGET，就不能进行普通利润提取。权益达到 `A + targetProfit` 后，Relayer 经检查写入 `TargetReached`，关闭按普通比例分配利润。

## 白名单

当前名单就是交易规则。未授权仓位会被平掉。其余仍在名单上的市场可继续交易。Admin 关闭保留普通关闭利润。

筛选、品牌和协议外定价仍由你负责。额外的评估规则需要你自行执行，funded 账户不会自动执行这些规则。
