## 允许什么

Funded 账户在限额内没有交易风格限制。你可以操作分配到该账户的资本，但不能自由提走 MainVault 拨付的本金。

## 追踪回撤

生命周期下限从 `A − R` 起步，并锁定**已接受峰值利润的 30%**。

下列公式中的 `D` 以基点（bps）表示：`D = 1000` 即 10%。

```
trailingFloor = A − A × D / 10_000 + 30% × max(peak − A, 0)
```

`A = $1,000`，`D = 1000`（10%），已接受峰值 `$1,200` → 下限 **`$960`**。存储的峰值仍为 `$1,200`。再次触及同一水平不会移动下限。

峰值记录已接受的权益数值，30% 只用于计算下限。权益严格低于下限才算触发回撤；等于下限不触发。权益不大于零始终触发回撤。

日内，`syncRiskState` 可在相对上次已接受峰值上涨 **1%** 之后上调峰值。Keeper 仅在一笔成交的已实现 PnL 为正后评估这次更新，单独的标记价格上涨不会触发。每日 `checkpoint` 接受任何更高的生命周期峰值，不要求达到 1%。

## 日回撤

仅出资方账户。自费没有日下限。

日限额为 `D` 的**一半**，并对日峰值套用同样的 30% 锁定：

```
dailyFloor = dayStart − dayStart × D / 20_000 + 30% × max(dailyPeak − dayStart, 0)
effectiveFloor = max(trailingFloor, dailyFloor)
```

同一示例，日初 `$1,000`，日峰值 `$1,200` → 日下限 **`$1,010`**。下限不叠加。

成功领取利润后，峰值和日基准重置为 `A`，盈利日计数归零。下限按 `A` 重新计算，而不是变成 `A` 本身。上例中，追踪下限回到 $900，日下限回到 $950。

## TARGET

`targetProfit` 是激活时确定的目标利润金额，以 USDC 计价。零表示不启用目标。

```
reached when currentEquity ≥ A + targetProfit
```

任何非零 TARGET 都会禁用账户运行期间的利润提取，包括尚未达到目标时。普通利润只能通过关闭结算领取。每次检查都先判断回撤，再判断 TARGET。

达到目标后，由 relayer 写入 `TargetReached`，进入现有关闭流程并保留普通分成。所有者提交的关闭意向不会锁定关闭原因；后续检查仍先判断回撤，再判断 TARGET。

## 市场

只能交易当前 MainVault 永续名单，并受该市场当前杠杆上限约束。

白名单编辑不会关闭账户。Proxy 拒绝名单外的新开仓。Keeper 平掉已撤市场上的剩余仓位。

没有全局 5× 上限。没有“未授权市场 → 账户关闭”的规则。`UnauthorizedAsset` 和 `LeverageBreach` 留在枚举里是为了 ABI。当前克隆不会写入它们。

## 时间

| 模式 | 时间如何支付 | 到期时发生什么 |
|---|---|---|
| 出资方账户 | 30 天订阅，每期为 `A` 的 1.5%（向上取整到 1 USDC），vault / 协议 50/50 | 若能用利润支付且不突破下限，`checkpoint` 可在最后 3 天续期。取消后，在该续期窗口内的下一个 checkpoint 关闭并保留普通分成；若先到期，则按到期关闭 |
| 自费 | 预付：2% / 1 天，4% / 7 天，8% / 30 天 | 不自动续期。到期保留普通分成。只有账户所有者可以在到期前用 `extendRental` 延长，档位相同，不加 `R`，预付期限最多延至当前时间的 30 天后 |

出资方账户激活时获得首个 30 天周期，之后的续期按上表收费。自费期限在激活时一次预付完毕。

`cancelSubscription` 对自费账户无效，不能用它主动提前关闭并保留普通分成。自费账户到期、达到 TARGET 或由管理员关闭时保留普通分成；主动提交 `TraderRequested` 则使用没收分成。

## 激活时

- `A`：默认 $10-$20,000
- `D`：默认 5%-25%
- `builderPoolBps`：普通利润的 10%-70%。必填
- `targetProfit`：以 USDC 计价的目标利润金额，零表示不启用目标
- `feeBps`：出资方路径只能是 200。自费 200 / 400 / 800 → 1 / 7 / 30 天

日回撤不是参数。出资方账户有，自费账户没有。
