普通利润由交易员和出资方两方分成，Vault 和协议不参与这部分分配。

```
builderShare = floor(profit × builderPoolBps / 10_000)
traderShare  = profit − builderShare
```

`builderPoolBps` 在激活时锁定，范围为 10%-70%。例如，设为 2000 时，出资方获得 20%，交易员获得 80%；这不是协议固定分成。

自费账户的两部分普通利润都归同一地址，因此交易员获得 100% 的普通利润。

协议与 LP 的收入来自溢价和订阅，不是来自保留利润的提取。被没收盈余由出资方与协议平分，LP 不拿。

## 提取利润

利润是当前权益超过账户规模 `A` 的部分，不按高水位计算。只有未设置利润目标的账户可以在运行期间提取利润。

必须同时满足：

- 账户为 Active，期限仍有效
- 没有待处理的交易员关闭意向
- 未设置 TARGET（`targetProfit = 0`）
- 利润至少 $1
- 账户已平仓
- 有足够的可交易 Core USDC
- 没有尚未完成的订阅费转账

然后满足以下任一：

- **3** 个盈利 checkpoint 日（权益相对上一次 checkpoint 至少增长 **0.70%**）
- 利润 **≥ `A` 的 1.5%**

提交请求时会记录全部利润的快照，并将这笔 USDC 从 Core 桥接到 EVM。`claimWithdrawal` 按约定比例分配利润：交易员应得的部分由克隆合约转出，出资方应得的部分记入领取账本。

`claimWithdrawal` 确认资金到账后，生命周期峰值、日基准和日峰值重置为 `A`，盈利日计数归零。下限按新的基准重新计算。例如，`A = $1,000`、回撤 10% 时，追踪下限回到 $900，出资方账户的日下限回到 $950。Core 拒绝发送时可以取消请求；取消不会降低已存储的峰值。

一日自费期限的首次 checkpoint 要等到期限结束。因此，未设置 TARGET 时，期内提取只能走 1.5% 路径。

## 关闭

关闭原因只记录一次。权益下限用于判断何时触发回撤关闭，本身不产生费用；关闭结算使用已记录的快照 `Q`。

| 原因 | 未提取的 `max(Q − A, 0)` |
|---|---|
| Drawdown | 没收 |
| TraderRequested | 没收 |
| TARGET | 普通分成 |
| 订阅到期 | 普通分成 |
| 订阅取消（出资方账户） | 普通分成 |
| Admin | 普通分成 |

表中的没收指交易员分成归零。自费账户的交易员同时也是出资方，因此仍以出资方身份获得被没收利润的 50%，协议获得其余部分。

已接受的待处理利润提取通常作为独立款项保留，并按 `builderPoolBps` 分成；关闭原因本身不会将其没收。

<Note>
当前实现有一项超时例外：进入 `Closing` 满 7 天后，如果 EVM 余额仍不足以覆盖待付款项，调用 `closeAndReturn` 可以冲销未到账的缺口。仍留在 Core 的相应金额会计入 `Q`，按该关闭原因结算；极端延迟的转账也可能失去原先的分配安排。这不是自动扣款，也不改变 `Returning` 阶段必须足额收到快照资金才能结算的要求。
</Note>

### 被没收的盈余

```
closeProfit = max(Q − A, 0)
builder    = floor(closeProfit × 5_000 / 10_000)
protocol   = closeProfit − builder
vault / LP = 0
trader     = 0
```

未使用的 `R` 退给 `reserveRecipient`。直接出资时是出资方，自费时是交易员；通过 ChallengeVault 激活时，退回其中的出资方运营余额。只有实际本金亏损才会消耗准备金。

### 自愿关闭

已平仓的账户所有者可以请求关闭。这先记录关闭意向；确认没有挂单或持仓、也没有更优先的关闭原因后，relayer 才提交 `TraderRequested`。未设置 TARGET 且满足提取条件时，应先提取并领取利润。设置了 TARGET 的账户只能通过保留分成的关闭领取普通利润。

## 结算

```
principalLoss   = max(A − Q, 0)
reserveConsumed = min(R, principalLoss)
reserveRefund   = R − reserveConsumed
closeProfit     = max(Q − A, 0)
```

关闭利润记入固定收款方的领取账本，随后通过 `claimPayout` 领取。

任何人都可以调用 `claimPayout(recipient)`。资金只能到达该地址。多个账户可以汇总到同一收款方。

Vault 从溢价和订阅拿到的部分已经在 NAV 里。它不进领取账本。

<Warning>
没收性关闭会将交易员对未提取关闭利润的分成清零；自费账户仍获得出资方的一半。若未设置 TARGET 且仍符合提取条件，先提取并领取。
</Warning>
