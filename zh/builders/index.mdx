Builder 为交易员打开一个 `FundedAccount`。MainVault 拨付本金，记账你的准备金，并走一条关闭结算路径。筛选、品牌与协议外定价仍归你。

Builder 就是支付 `R + P` 的人。没有登记表，没有 `registerBuilder`，没有 $10 质押，也没有 10× 容量。任何有 USDC 支付激活费用的钱包，都可以为自己或他人开户。

| 你的层 | 协议层 |
|---|---|
| 筛选与品牌 | 来自 MainVault 的本金 |
| 协议外项目定价 | 下限、TARGET、当前白名单 |
| 你如何找到交易员 | 准备金退回、普通分成、被没收的盈余 |

<Warning>
来自 funded 账户的 Hyperliquid builder-code 费用进入 `protocolFeeReceiver`，不是 Builder。
</Warning>

## 收益

<CardGroup cols={2}>
  <Card title="未使用的准备金" icon="shield">
    `R` 是你的。实际本金亏损按 1:1 消耗。其余退回
  </Card>
  <Card title="普通利润" icon="split">
    保留利润提取与非没收性关闭中的 `builderPoolBps`（10–70%）
  </Card>
  <Card title="被没收的盈余" icon="percent">
    Drawdown 或 TraderRequested 之后，实际 `Q − A` 的 40%
  </Card>
  <Card title="LP shares" icon="trending-up">
    如果你也是 LP，shares 拿同样的残值 vault 收入，也承担同样的亏损。这是可选的。激活不需要 shares
  </Card>
</CardGroup>

Builder 不拿订阅费。订阅按 50/50 分给 vault / 协议。

第一损失是准备金 `R`，不是第二次 vault 存款。规模由 vault 限制：利用率 80%，单账户最多 NAV 的 10%。
