MainVault 管理 LP 存款、funded 账户本金、出资方准备金和 funded 结算。LP 持有 vault 份额，其价值随净资产变化。

## 净资产与份额

在账户结算前，vault 按原始本金计算该账户，因此未结算的盈亏不会影响存款和退出时的份额价格。

超出准备金的亏损会立即降低 NAV，并记为 Vault 债务。只有没收性关闭才会从被关闭账户未使用的准备金中偿还一部分，金额有上限且没有保证；偿还金额在 7 天内逐步计入 NAV。详见[收益与风险](/zh/vault/yield)。

所有者可以将闲置 USDC 存入 Hyperlend，利息同样会提高份额价格。

## 上限

| 参数 | 当前设置 | 限制什么 |
|---|---|---|
| 最大利用率 | **80%** | 拨付给 funded 账户的资本相对 vault 资产 |
| 单账户上限 | **10%** / \$20k | 单个 funded 账户的规模 |
| 账户规模 | \$10-\$20,000 | 每账户 `A` |
| 回撤 | 5%-25% | 追踪回撤 |
| Vault 上限 | \$25,000 | Vault 资产 |

激活还需要 NAV 至少 \$100；低于该值时仍可存款。

## 退出

LP 退出无需提前通知或等待冷却期，但必须满足流动性和利用率限制。

退出只能动用未被准备金、退款与派付负债占用的 USDC。若部分资金存于 Hyperlend，vault 会从中赎回所需的差额；Hyperlend 无法支付时，退出失败。退出后的利用率不得超过上限。开放的 funded 账户不会锁定 LP 份额。

协议暂停时，LP 无法退出，但交易员和出资方仍可领取派付。所有者或 relayer 可以暂停，只有所有者可以解除暂停。

## 治理

所有者可以调整账户规模和回撤区间、利用率上限和各项限额。利用率、单账户占 NAV 比例和最大回撤有固定边界；账户规模与 vault 上限可以提高，没有固定上限。

费用档位、允许的利润分成范围、没收分成及订阅费乘数写在代码中，修改需要升级合约。MainVault 的升级与风险参数修改都需在时间锁中等待 72 小时。参见[安全](/zh/security)。
