## Review

The codebase is reviewed by hand on an ongoing basis. That does not replace an independent audit.

## Admin

Critical actions sit behind a 3-of-5 multisig and timelocks. Parameters move only inside published bounds. One compromised key is not enough.

| Minimum delay | Changes |
| --- | --- |
| **72 hours** | `MainVault` upgrades, `transferOwnership`, migrations that replace the vault implementation |
| **48 hours** | `queueFactoryChange` / `executeFactoryChange`, `setRelayer`, `setForwarder`, `setRiskConfig`, adding a market, raising leverage |

<Note>
  Risk-reducing actions can run immediately: pause activations, cancel a queued change, remove a market, lower leverage. Unpausing or raising risk waits for the timelock.
</Note>
