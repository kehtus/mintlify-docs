---

参数由你在允许区间内选择。账户一旦激活，回撤、利润分成和结算规则你和交易员都改不了；市场白名单仍可由协议更新。

| 规则 | 取值 |
|---|---|
| 普通利润 | 你按激活时定下的比例分成，其余归交易员。Vault 和协议不参与分成 |
| 被没收的盈余 | 你得 50%，协议得其余。Vault 和 LP 不参与分成 |
| 利润锁定 | 已接受峰值利润的 30%，计入追踪下限和日下限 |
| Vault 债务 | vault 有债务时，没收性关闭会从未使用的 `R` 中留下一部分偿还，上限见[参数与费用](/zh/backers/fees) |
| 出资期限 | 30 天订阅 |
| 日回撤 | 出资方账户有，自费账户没有 |
| 谁可以出资 | 任何有 `R + P` 的人 |
| 市场 | 当前 vault 白名单。编辑不会关闭账户 |

## 追踪下限

```
A = $1,000, D = 10%, accepted peak = $1,200
baseFloor  = $900
profitLock = $60
trailing   = $960
```

利润领取完成后，峰值重置为 `A`；追踪下限回到 `A − R`，并非 `A`。

## 日回撤

这不是你设置的参数：出资方账户一律启用，为 `D` 的一半；自费账户没有。

同一示例，日初 `$1,000`，日峰值 `$1,200` → 日下限 `$1,010`。有效下限取二者较大值。

## TARGET

TARGET 是激活时设定的绝对利润金额，零表示不启用。设置后不能中途提取利润；权益达到 `A` 加该金额时，账户按普通分成关闭。

## 白名单

当前名单就是交易规则：已撤市场上的仓位会被平掉，其余市场继续交易，账户不关闭。管理员关闭保留普通分成。

筛选、品牌和协议外定价仍由你负责。你额外定的评估规则也要自己执行，funded 账户不会替你执行。
