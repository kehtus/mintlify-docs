## What you choose

| Parameter | Band | Role |
|---|---|---|
| `trader` | any address | Clone owner. If `trader` is the caller, the path is self-funded |
| `accountSize` | $10-$20,000 | Principal `A` |
| `drawdownBps` | 5%-25% | Trailing `D`. Sets reserve `R` |
| `builderPoolBps` | 10%-70% | Ordinary builder share |
| `targetProfit` | ≥ 0 | Absolute TARGET. `0` disables |
| `feeBps` | 200 / 400 / 800 | Sponsored must pass **200**. Self-funded picks the term |
| `proposedReferrer` | optional | Binds the caller |

Daily drawdown follows the path: sponsored on, self-funded off.

## Activation charge

```
R = floor(A × D / 10_000)     // builder-owned reserve
P = ceil(A × F / 10_000)      // premium, a share of A, not of R
activationCharge = R + P
```

Raising `D` costs more refundable reserve. It does not raise the premium.

| Path | `F` | Term |
|---|---|---|
| Sponsored | 2% | 30 days, renewing subscription |
| Self-funded T1 | 2% | 1 day prepaid |
| Self-funded T2 | 4% | 7 days prepaid |
| Self-funded T3 | 8% | 30 days prepaid |

```
protocolPremium = floor(P × 50%)
vaultPremium    = P − protocolPremium
```

The caller pays `R + P` in USDC. MainVault deposits exactly `A`.

Example: `A = $1,000`, `D = 10%`, sponsored 2% → `R = $100`, `P = $20`, charge `$120`. Vault and protocol take `$10` of premium each. Reserve `$100`. Allocation `$1,000`.

## Allocation limits

| Limit | Default | Meaning |
|---|---|---|
| Max utilization | 80% of NAV | Share of vault in active accounts |
| Max single account | 10% of NAV, cap $20k | One `A` |

No activation until NAV reaches the bootstrap floor ($100 at defaults). Deposits still work below that.

## Subscription

```
subscriptionFee = ceil_to_1_USDC(A × 1.5%)
```

50/50 vault / protocol. Builder gets 0.

Sponsored accounts can renew from Core equity in the last 3 days if the fee does not breach floors. Self-funded uses `extendRental`: same tiers, no extra `R`, horizon now + 30 days.

## Profit and close

Live withdrawal and non-forfeiting close use `builderPoolBps`. Forfeiting close (`Drawdown`, `TraderRequested`) zeros unwithdrawn `Q − A` and splits it 40 / 20 / LP residual. Unused `R` still returns to `reserveRecipient`.

Admin close keeps the ordinary split.
