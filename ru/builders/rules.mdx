---
title: "Жёсткие правила"
description: "Что нельзя смягчить после активации"
---

Параметры выбираете внутри коридоров. После активации полы, сплиты и экономику close переписать нельзя.

| Правило | Значение |
|---|---|
| Обычная прибыль | `builderPoolBps` билдеру, остаток трейдеру. Волт и протокол берут 0 |
| Конфискованный surplus | Билдер 40% / протокол 20% / LP остаток |
| Лок профита | 30% принятой пиковой прибыли, на lifetime и daily |
| Вывод | 3 прибыльных checkpoint-дня (≥ 0.70%) или профит ≥ 3% от `A` |
| Checkpoint | 1 день |
| Спонсируемый срок | Подписка 30 дней |
| Daily drawdown | Есть на спонсируемом, нет на self-funded |
| Кто может спонсировать | Любой с `R + P` |
| Рынки | Живой whitelist MainVault. Правка счёт не закрывает |

## Trailing floor

```
A = $1,000, D = 10%, принятый пик = $1,200
baseFloor  = $900
profitLock = $60
trailing   = $960
```

Intraday пики двигаются после порога 1%. Checkpoint принимает любой более высокий lifetime-пик. После подтверждённого вывода пики сбрасываются на `A`.

## Daily drawdown

Это не флаг на активации. Спонсируемый: включён, половина `D`. Self-funded: выключен.

Тот же пример, старт дня `$1,000`, дневной пик `$1,200` → дневной пол `$1,010`. Рабочий пол это максимум двух.

## TARGET

`targetProfit` ончейн. Ноль выключает. Порог `A + targetProfit` блокирует обычный вывод. Relayer пишет `TargetReached` и сохраняет обычный сплит.

## Whitelist

Живой список это правило торговли. Лишний размер сворачивается. Остальные live-рынки остаются открытыми. Admin close сохраняет обычный профит close.

Отбор, бренд и цена снаружи остаются вашими.
