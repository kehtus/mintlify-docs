普通利润由交易员和出资方两方分成，Vault 和协议不参与这部分分配。

出资方分成在激活时锁定，范围为 10%-70%。例如，出资方分成为 20% 时，交易员获得 80%；这个比例不是协议固定的。

自费账户的两部分普通利润都归同一地址，因此交易员获得 100% 的普通利润。

## 提取利润

利润是当前权益超过账户规模 `A` 的部分，每次提取会取走全部利润。只有未设置目标利润的账户可以在运行期间提取利润。

必须同时满足：

- 账户正常运行，期限仍有效
- 没有待处理的关闭请求
- 未设置 TARGET
- 利润至少 \$1
- 账户已平仓
- 有足够的可交易 Core USDC
- 没有尚未完成的订阅费转账

然后满足以下任一：

- **3** 个盈利日（权益比上一日至少增长 **0.70%**）
- 利润 **≥ `A` 的 1.5%**

提交请求后，利润从 HyperCore 转到 HyperEVM。领取时，交易员的部分转到交易员地址，出资方的部分记入领取账本。

提取完成后，下限和盈利日计数重置。例如，`A = $1,000`、回撤 10% 时，追踪下限回到 \$900，出资方账户的日下限回到 \$950。

一天期的自费账户来不及凑够盈利日，期内提取只能走 1.5% 路径。

## 关闭

| 原因 | 账户中剩余的利润 |
|---|---|
| 回撤突破 | 没收 |
| 交易员申请关闭 | 没收 |
| 达到 TARGET | 普通分成 |
| 订阅到期 | 普通分成 |
| 订阅取消（出资方账户） | 普通分成 |
| 管理员关闭 | 普通分成 |

自费账户的交易员同时也是出资方，因此仍以出资方身份获得被没收利润的一半，协议获得其余部分。

已经请求提取的利润按普通分成支付，关闭原因不会将其没收。少数情况下，若这笔转账在关闭开始一周后仍未到账，未到账部分可能不再按普通分成支付。

### 被没收的盈余

被没收的利润由出资方与协议平分，Vault、LP 和交易员都不拿。

未使用的 `R` 退给出资方（自费时退给交易员）。只有实际本金亏损才会消耗准备金。Vault 有债务时，没收性关闭会先从未使用的 `R` 中留下一部分偿还债务，其余照常退回；这不影响交易员应得的利润。详见[收益与风险](/zh/vault/yield)。

### 自愿关闭

已平仓的账户所有者可以请求关闭，但这是没收性关闭。所以未设置 TARGET 且满足提取条件时，应先提取并领取利润，再请求关闭。设置了 TARGET 的账户只能通过普通关闭领取普通利润。

## 结算

结算后，应付款项记入收款方的领取账本。任何人都可以调用 `claimPayout` 将其发到该地址，资金无法被转往别处。
