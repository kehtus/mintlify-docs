`FundedAccount` это изолированный клон на HyperEVM. MainVault кладёт принципал `A` на Hypercore. Торговля идёт через API-кошелёк. Exchange Proxy подписывает Hyperliquid. Сырой ключ трейдеру не выдаётся.

| | Спонсируемый | Self-funded |
|---|---|---|
| Кто платит `R + P` | Вызывающий. Он же `record.builder` | Трейдер |
| Принципал `A` | Из MainVault | Из MainVault |
| Daily drawdown | Есть | Нет |
| Время | Подписка 30 дней, может продлиться | Предоплата 1 / 7 / 30 дней |
| Обычная прибыль | Сплит по `builderPoolBps` | Те же формулы, оба куска трейдеру |

Self-funded это `activateFunded`, когда вызывающий и есть трейдер. Lifetime-пол тот же. Дневного пола нет.

Живой список MainVault это единственный список рынков. Правка счёт не закрывает. Входы вне списка отклоняются. Остаток на снятом рынке сворачивается.

```
активация → Active → торговля
                   → вывод профита (необязательно)
                   → закрытие → сеттлмент → claim
```

Закрытие одно. Клон снимает торговый капитал Core `Q`. MainVault берёт замороженную запись и начисляет pull-леджер.
