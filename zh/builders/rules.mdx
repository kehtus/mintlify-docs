---
title: "硬性规则"
description: "激活之后 Builder 不能放宽的部分"
---

你在允许区间内选择参数。账户上线后，你不能改写下限、分成或关闭经济。

| 规则 | 取值 |
|---|---|
| 普通利润 | `builderPoolBps` 给 Builder，剩余给交易员。Vault 和协议拿 0 |
| 被没收的关闭盈余 | Builder 40% / 协议 20% / LP 残值 |
| 利润锁定 | 已接受峰值利润的 30%，同时作用于生命周期下限与日下限 |
| 提取门槛 | 3 个盈利 checkpoint 日（增长 ≥ 0.70%）**或** 利润 ≥ `A` 的 3% |
| Checkpoint | 1 天 |
| 赞助期限 | 30 天订阅 |
| 日回撤 | 赞助账户强制开启，自费账户关闭 |
| 谁可以赞助 | 任何有 `R + P` 的人。没有登记表，没有质押 |
| 市场 | 当前 MainVault 白名单。编辑不会关闭账户 |

## 追踪下限

```
A = $1,000, D = 10%, accepted peak = $1,200
baseFloor  = $900
profitLock = $60
trailing   = $960
```

日内峰值只有在通过 1% 接受门槛后才会移动。Checkpoint 接受任何更高的生命周期峰值。已证实的利润领取之后，峰值重置为 `A`。

## 日回撤

不是你在激活时传入的开关。若你赞助另一名交易员，日回撤按 `D` 的一半开启。若交易员自费，则关闭。

同一示例，日初 `$1,000`，日峰值 `$1,200` → 日下限 `$1,010`。有效下限取二者较大值。

## TARGET

`targetProfit` 在链上。零表示关闭。`A + targetProfit` 这个阈值会挡住普通提取。Relayer 写入 `TargetReached`，并保留普通分成。

## 白名单

当前名单是每个 Active 账户的交易规则。未授权仓位会被平掉。其余仍在名单上的市场可继续交易。整户紧急关闭是 Admin，且 Admin **保留**普通关闭利润。

## 你仍然拥有什么

如何筛选交易员、你在协议外向他们收取什么，以及如何打造项目品牌，都仍归你。一旦 `activateFunded` 落地，资本保护归协议。
