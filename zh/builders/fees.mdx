## 你选择什么

| 参数 | 区间 | 作用 |
|---|---|---|
| `trader` | 任意地址 | 克隆所有者。若 `trader` 是调用方，则走自费路径 |
| `accountSize` | $10-$20,000 | 本金 `A` |
| `drawdownBps` | 5%-25% | 追踪 `D`。决定准备金 `R` |
| `builderPoolBps` | 10%-70% | 普通 Builder 份额 |
| `targetProfit` | ≥ 0 | 绝对 TARGET。`0` 表示关闭 |
| `feeBps` | 200 / 400 / 800 | 赞助必须传入 **200**。自费选择期限 |
| `proposedReferrer` | 可选 | 绑定调用方 |

日回撤不是参数。赞助开，自费关。

## 激活费用

```
R = floor(A × D / 10_000)     // builder-owned reserve
P = ceil(A × F / 10_000)      // premium, a share of A, not of R
activationCharge = R + P
```

提高 `D` 会增加可退还的准备金。它不会提高溢价。

| 路径 | `F` | 期限 |
|---|---|---|
| 赞助 | 2% | 30 天，可续期订阅 |
| 自费 T1 | 2% | 预付 1 天 |
| 自费 T2 | 4% | 预付 7 天 |
| 自费 T3 | 8% | 预付 30 天 |

```
protocolPremium = floor(P × 50%)
vaultPremium    = P − protocolPremium
```

调用方以 USDC 支付 `R + P`。MainVault 存入恰好 `A`。

示例：`A = $1,000`，`D = 10%`，赞助 2% → `R = $100`，`P = $20`，费用 `$120`。Vault 与协议各拿溢价中的 `$10`。准备金 `$100`。拨付 `$1,000`。

## 拨付上限

激活不需要 vault 存款。上限由 vault 自己切：

| 上限 | 默认 | 含义 |
|---|---|---|
| 最大利用率 | NAV 的 80% | 拨付给在途账户的 vault 份额 |
| 单账户上限 | NAV 的 10%，封顶 $20k | 单个 `A` |

在 NAV 达到启动下限（默认 $100）之前，任何账户都不能激活。低于该值时仍可存款。

## 订阅

```
subscriptionFee = ceil_to_1_USDC(A × 1.5%)
```

按 50/50 分给 vault / 协议。Builder 获得 0。

赞助账户可在周期最后 3 天用 Core 权益续期，前提是支付费用不会突破下限。自费走 `extendRental`：同一档位，不加 `R`，最多提前 30 天。

## 利润与关闭

在途提取与非没收性关闭使用 `builderPoolBps`。没收性关闭（`Drawdown`、`TraderRequested`）将未提取的 `Q − A` 清零，并按 40 / 20 / LP 残值分配。未使用的 `R` 仍退给 `reserveRecipient`。

Admin 关闭保留普通分成。这是紧急出口，不是没收。

funded 账户产生的 Hyperliquid builder-code 费用进入 `protocolFeeReceiver`，不是 Builder。
