> 你做产品。Proportion 提供 funded 层：资本，开箱即用。

对 Builder 来说，funded 账户是 prop firm 里最吃资本、也最吃基础设施的部分。Proportion 把它做成服务：资本、链上风控引擎、结算。筛选、品牌、营销和协议外定价仍归你。

Builder 向协议购买资本：支付准备金 `R` 加溢价 `P`。未使用的准备金在关闭时退回。`builder` 就是付款人。没有登记册。激活不需要 vault 存款。任何有 USDC 支付 `R + P` 的钱包都可以为自己或他人开户。

界限很简单。`activateFunded` 之前都是你的。激活之后，由协议保护资本。

<Warning>
funded 账户产生的 Hyperliquid builder-code 费用进入 `protocolFeeReceiver`，不是 Builder。
</Warning>

## 协议提供什么

| Builder 层 | 协议层 |
|---|---|
| 筛选与品牌 | 来自 MainVault 的本金 |
| 协议外项目定价 | 下限、TARGET、当前白名单 |
| 你如何找到交易员 | 准备金退还、普通分成、被没收盈余 |

funded 账户是带本金 `A`、准备金 `R` 和自动风控的隔离克隆。在协议规则内，账户属于交易员。

## Builder 损益

<CardGroup cols={2}>
  <Card title="未使用的准备金" icon="shield">
    `R` 是你的。实际本金亏损按 1:1 消耗。其余退回
  </Card>
  <Card title="普通利润" icon="split">
    保留利润提取与非没收性关闭中的 `builderPoolBps`（10-70%）
  </Card>
  <Card title="被没收的盈余" icon="percent">
    Drawdown 或 TraderRequested 之后，实际 `Q − A` 的 40%
  </Card>
  <Card title="LP shares" icon="trending-up">
    可选。同样的残值 vault 收入，同样的亏损。激活不需要 shares
  </Card>
</CardGroup>

Builder 不拿订阅费。订阅按 50/50 分给 vault / 协议。

第一损失是准备金 `R`，不是第二笔 vault 存款。规模由 vault 限制：利用率 80%，单账户最多 NAV 的 10%。

更多关于 vault 收益与风险：[Vault](/zh/vault/yield)。
