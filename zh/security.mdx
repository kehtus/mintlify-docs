## 资金托管

Proportion 是非托管协议。资金由合约持有，不由团队或任何其他人持有。每一笔派付都记入固定地址，领取无需任何人批准，vault 暂停期间也可以领取。风控 keeper 和 exchange proxy 通过 Hyperliquid API 钱包交易，这类钱包不能提取或转移资金。

## 审计

智能合约已完成独立安全审计。审计仅覆盖报告中列明的代码版本和范围，并不代表之后的所有变更都已通过审计。

**审计报告：** [查看安全审计报告](https://beosin.com/audits/Proportion_202603161420.pdf)

## 审查

代码会持续人工复查。这不能替代独立审计。

## 合约变更

合约变更须经多签钱包和 72 小时时间锁：变更先在链上排队，延迟期满后才能生效，因此任何人都能提前看到。保护性操作立即生效。

| 在时间锁中等待 72 小时 | 立即生效 |
| --- | --- |
| `MainVault` 和 `ChallengeVault` 升级、所有权变更、工厂与集成变更（如 `setRelayer`、`setForwarder`）、`setRiskConfig`、增加市场和提高杠杆上限、解除暂停 | 暂停 vault、取消已排队的变更、停止购买 Challenge、移除市场、降低杠杆上限 |

风控 relayer 不能升级合约、修改参数或解除暂停。
