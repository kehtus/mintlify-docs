Proportion 的中心是 MainVault 合约。LP 存款、funded 账户本金、Builder 准备金记账和单一关闭路径都在这里汇合。系统里任何移动资本的动作都经过这个 vault。

## 保守 NAV

```
grossAssets = EVM USDC + totalAllocated

totalAssets = grossAssets
            − active builder reserve
            − claimable reserve refunds
            − claimable payouts

sharePrice  = totalAssets / totalShares     // 1 USDC if no shares
```

准备金、未支付退款和未支付领取不会抬高 share price。在关闭实现 `Q` 之前，存款与退出使用这一链上状态。

## 上限

| 参数 | 默认 | 限制什么 |
|---|---|---|
| 最大利用率 | **80%** | `totalAllocated` 相对 NAV |
| 单账户上限 | **10%** / $20k | 单个 `A` |
| 账户规模 | $10-$20,000 | 每账户 `A` |
| 回撤 | 5%-25% | 追踪 `D` |

激活还需要 NAV ≥ $100（默认 `minAccountSize / maxSingleAccountBps`）。低于该值时仍可存款。

## 退出

`withdraw(shares)` 即时可用。`requestWithdraw` / `executeWithdraw` 是同一套核算上的可选 1 天冷却。

退出只能动用高于准备金、退款与派付负债的 EVM 现金。利用率必须保持完好。打开的 funded 账户不会锁定 shares。

`deposit(amount, proposedReferrer)` 可在首次接触时绑定 LP 的推荐。`depositFor` 从不绑定。

## 治理

风险区间、利用率与上限通过 `setRiskConfig` 调整。费用档位和 50/50 分成是常量。
