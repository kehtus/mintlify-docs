> 你负责产品。Proportion 提供 funded 层。

<Note>
Proportion 尚未向公众开放。本节说明协议实现的出资方流程。
</Note>

对出资方来说，funded 账户需要投入资本和交易基础设施。Proportion 提供资本、合约风控规则、链下风控执行和结算。筛选、品牌、营销和协议外定价仍由你负责。

出资方支付准备金 `R` 加溢价 `P`，由 vault 拨付交易资本。未使用的准备金在关闭时退回。直接调用 `activateFunded` 时，付款钱包就是 `builder`；通过挑战晋级或融资挂牌开户时，由 `ChallengeVault` 付款并记录该挑战或挂牌指定的出资方。直接激活没有登记要求，也不需要 vault 存款，但须满足 vault 的容量限制。

你决定为谁开户及其商业条款。协议执行 funded 账户的资本规则和结算。

## 协议提供什么

| 出资方层 | 协议层 |
|---|---|
| 筛选与品牌 | 来自 MainVault 的本金 |
| 协议外项目定价 | 下限、TARGET、当前白名单 |
| 你如何找到交易员 | 准备金退还、普通分成、被没收盈余 |

funded 账户是带本金 `A`、准备金 `R` 和自动风控的隔离克隆。在协议规则内，账户属于交易员。

##出资方损益

<CardGroup cols={2}>
  <Card title="未使用的准备金" icon="shield">
    `R` 是你的。实际本金亏损按 1:1 消耗。其余退回
  </Card>
  <Card title="普通利润" icon="split">
    在普通利润提取和非没收性关闭时，按 `builderPoolBps` 获得利润分成（10%–70%）
  </Card>
  <Card title="被没收的盈余" icon="percent">
    Drawdown 或 TraderRequested 之后，实际正利润 `max(Q − A, 0)` 的 50%
  </Card>
  <Card title="LP shares" icon="trending-up">
    参与 vault 收益与亏损。直接激活不要求持有份额；发布和销售挑战计划则要求持有份额，并满足已配置的最低持仓价值
  </Card>
</CardGroup>

出资方不拿订阅费。订阅按 50/50 分给 vault / 协议。

准备金 `R` 首先承担本金损失。它独立于 LP 存款。规模受 vault 限制：利用率 80%，单账户上限为 NAV 的 10% 与 $20,000 中的较小值。

更多关于 vault 收益与风险：[Vault](/zh/vault/yield)。
