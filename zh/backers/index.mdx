> 你负责产品。Proportion 提供 funded 层。

funded 账户是 prop 产品里最占资本的一环，所以由 Proportion 承担：提供资本、执行下限并完成结算。筛选、品牌、营销和协议外定价仍由你负责。

出资方支付准备金 `R` 加溢价 `P`，由 vault 拨付交易资本。未使用的准备金在关闭时退回。直接激活时，付款的钱包就是出资方；通过挑战晋级或融资挂牌开户时，出资方是其中指定的人。直接激活无需登记，也不需要 vault 存款。

你决定为谁开户及其商业条款。

## 协议提供什么

| 出资方层 | 协议层 |
|---|---|
| 筛选与品牌 | 来自 vault 的本金 |
| 协议外项目定价 | 下限、TARGET、当前白名单 |
| 你如何找到交易员 | 准备金退还、普通分成、被没收盈余 |

funded 账户是带本金 `A`、准备金 `R` 和自动风控的隔离账户。在协议规则内，账户属于交易员。

## 出资方损益

<CardGroup cols={2}>
  <Card title="未使用的准备金" icon="shield">
    `R` 是你的钱：交易员亏多少就消耗多少，其余退回；vault 有债务时，没收性关闭会从中留下一部分偿还
  </Card>
  <Card title="普通利润" icon="split">
    每次利润提取和普通关闭，你都按激活时定下的比例（10%–70%）分得利润
  </Card>
  <Card title="被没收的盈余" icon="percent">
    账户因跌破下限或交易员主动申请而关闭时，剩余利润的 50% 归你
  </Card>
  <Card title="LP shares" icon="trending-up">
    开户不需要持有份额；发布和销售挑战计划才需要，并要满足已配置的最低持仓价值。份额参与 vault 的收益与亏损
  </Card>
</CardGroup>

订阅费不是你的收入：它分给 vault 和协议。

准备金 `R` 与 LP 存款分开，最先承担亏损。账户规模受 vault 容量限制，见[参数与费用](/zh/backers/fees)。

Vault 的收益与风险见[Vault](/zh/vault/yield)。
