---
title: "Funded 账户"
description: "受合约规则约束的隔离 Hypercore 资本"
---

`FundedAccount` 是 HyperEVM 上的隔离克隆。MainVault 把本金 `A` 存入 Hypercore。交易经由 API 钱包。Exchange Proxy 为 Hyperliquid 签名。交易员从不持有该密钥。

| | 赞助 | 自费 |
|---|---|---|
| 谁付 `R + P` | 调用方。他们就是 `record.builder` | 交易员 |
| 本金 `A` | 来自 MainVault | 来自 MainVault |
| 日回撤 | 开 | 关 |
| 时间 | 30 天订阅，可续期 | 预付 1 / 7 / 30 天 |
| 普通利润 | 按 `builderPoolBps` 分成 | 同一套公式，两个桶都给交易员 |

自费就是调用方等于交易员时的 `activateFunded`。生命周期下限相同。没有日下限。

当前 MainVault 名单是唯一市场名单。编辑不会关闭账户。名单外的新开仓会被拒绝。已撤市场上的剩余仓位会被平掉。

```
activate → Active → trade
                 → withdraw profit (optional)
                 → close → settle → claim
```

关闭只有一条路径。克隆快照 Core 交易资本 `Q`。MainVault 套用冻结记录并记入领取账本。
