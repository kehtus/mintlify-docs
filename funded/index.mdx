title: "Funded accounts"
description: "Isolated Hypercore capital under contract rules"
---

A `FundedAccount` is an isolated clone on HyperEVM. MainVault deposits principal `A` onto Hypercore. Trading goes through an API wallet. The Exchange Proxy signs Hyperliquid. The trader never holds that key.

| | Sponsored | Self-funded |
|---|---|---|
| Who pays `R + P` | The caller. They are `record.builder` | The trader |
| Principal `A` | From MainVault | From MainVault |
| Daily drawdown | On | Off |
| Time | 30-day subscription, can renew | Prepaid 1 / 7 / 30 days |
| Ordinary profit | Split by `builderPoolBps` | Same formulas, both buckets to the trader |

Self-funded is `activateFunded` when the caller is the trader. Lifetime floor is the same. No daily floor.

The live MainVault list is the only market list. An edit does not close the account. Off-list entries are refused. Leftover size on a withdrawn market is flattened.

```
activate → Active → trade
                 → withdraw profit (optional)
                 → close → settle → claim
```

Close is one path. The clone snapshots Core trading capital `Q`. MainVault applies the frozen record and credits a pull ledger.
