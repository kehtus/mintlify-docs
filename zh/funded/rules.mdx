## 允许什么

下面没禁止的都可以做。风格、频率、新闻、机器人、跟单、隔夜和周末，只要还在下限和当前市场名单内，都不受限。

| 活动 | 状态 |
|---|---|
| 跟单 | 可以 |
| 机器人和 EA | 可以 |
| 新闻 | 可以 |
| 基于信息的交易 | 可以 |

## 追踪回撤

生命周期下限从 `A − R` 起步，并锁定**已接受峰值利润的 30%**。

```
trailingFloor = A − A × D / 10_000 + 30% × max(peak − A, 0)
```

`A = $1,000`，`D = 10%`，已接受峰值 `$1,200` → 下限 **`$960`**。存储的峰值仍为 `$1,200`。再次触及同一水平不会移动下限。

峰值存储已接受权益。30% 锁定只在计算下限时套用。违约是严格小于。相等被允许。权益 ≤ 0 始终是违约。

日内，`syncRiskState` 可在相对上次已接受峰值上涨 **1%** 之后上调峰值。每日 `checkpoint` 接受任何更高的生命周期峰值。

## 日回撤

仅赞助账户。自费没有日下限。

日限额为 `D` 的**一半**，并对日峰值套用同样的 30% 锁定：

```
dailyFloor = dayStart − dayStart × D / 20_000 + 30% × max(dailyPeak − dayStart, 0)
effectiveFloor = max(trailingFloor, dailyFloor)
```

同一示例，日初 `$1,000`，日峰值 `$1,200` → 日下限 **`$1,010`**。下限不叠加。

已证实的利润领取之后，峰值重置为 `A`。下限视图从 `A` 起算，这样一次成功的划转不会看起来像 Drawdown。

## TARGET

`targetProfit` 是激活时冻结的绝对 USDC 金额。零表示关闭。

```
reached when currentEquity ≥ A + targetProfit
```

此前的提取不累计。始终先检查回撤。到阈值后，普通提取已经不能继续。

账户不会自己关闭。只有 relayer 写入 `TargetReached`。这是保留分成的关闭。如果所有者在阈值上手动关闭，第一步意向是 `TraderRequested`（没收）。Relayer 仍应优先写 TARGET。

## 市场

只能交易当前 MainVault 永续名单，并受该市场当前杠杆上限约束。

白名单编辑不会关闭账户。Proxy 拒绝名单外的新开仓。Keeper 平掉已撤市场上的剩余仓位。

没有全局 5× 上限。没有“未授权市场 → 账户关闭”的规则。`UnauthorizedAsset` 和 `LeverageBreach` 留在枚举里是为了 ABI。当前克隆不会写入它们。

## 时间

| 模式 | 时间如何支付 | 到期时发生什么 |
|---|---|---|
| 赞助 | 30 天订阅，每期为 `A` 的 1.5%（向上取整到 1 USDC），vault / 协议 50/50 | 若能用利润支付且不突破下限，`checkpoint` 可在最后 3 天续期。取消：下一个合格 checkpoint 关闭并保留普通分成 |
| 自费 | 预付：2% / 1 天，4% / 7 天，8% / 30 天 | 不自动续期。到期保留普通分成。任何人都可以用 `extendRental` 续时，档位相同，不加 `R`，最多提前 30 天 |

首个赞助周期不藏在激活费用里。自费期限一次预付完毕。

`cancelSubscription` 在自费路径上什么也不做。那条路径没有保留利润的提前退出：等到期，或走 `TraderRequested`。

## 激活时

- `A`：默认 $10-$20,000
- `D`：默认 5%-25%
- `builderPoolBps`：普通利润的 10%-70%。必填
- `targetProfit`：绝对 TARGET，或零
- `feeBps`：赞助只能是 200。自费 200 / 400 / 800 → 1 / 7 / 30 天

日回撤不是参数。赞助有，自费没有。
