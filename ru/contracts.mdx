Контракты протокола работают на HyperEVM, funded-аккаунты торгуют на HyperCore. Протокол ещё не открыт для пользователей. Суммы в контрактах HyperEVM учитываются в USDC с шестью знаками после запятой.

| | |
|---|---|
| Сеть | Основная сеть HyperEVM |
| Chain id | 999 |
| RPC | `https://rpc.hyperliquid.xyz/evm` |
| USDC | [`0xb88339CB7199b77E23DB6E890353E22632Ba630f`](https://hyperscan.com/address/0xb88339CB7199b77E23DB6E890353E22632Ba630f) |

## Funded-аккаунты

| Контракт | Что делает |
|---|---|
| `MainVault` (прокси) | Хранит USDC, выпускает доли LP, финансирует funded-аккаунты и проводит их расчёт. UUPS-прокси; владелец может заменить имплементацию |
| `MainVault`, имплементация | Логика vault, которую владелец может заменить через обновление прокси |
| `FundedAccountFactory` | Клонирует один `FundedAccount` на каждую активацию |
| `FundedAccount`, имплементация | Логика, на которую ссылаются создаваемые фабрикой клоны |
| `Forwarder` | ERC-2771-форвардер: передаёт подписанные запросы, а за газ платит релеер, который отправляет транзакцию |
| `ReferralRegistry` | Реферальные привязки, общие для funded-аккаунтов и челленджей |

## Челленджи

| Контракт | Что делает |
|---|---|
| `ChallengeVault` (прокси) | Единственный держатель USDC челленджей: блокировки покупок, исходы, перевод в funded-аккаунт. UUPS-прокси |
| `ChallengeVault`, имплементация | Логика vault, которую владелец может заменить через обновление прокси |
| `ChallengeFactory` | Оформление покупки: ценообразование, распределение комиссий, `buyChallenge` |
| `ChallengePlanRegistry` | Планы бэкеров: после публикации не меняются, но могут быть отключены |

## Роли

| Роль | Может |
|---|---|
| Владелец | Обновлять оба vault, менять параметры и интеграции, ставить на паузу и снимать её. Сегодня это один адрес; см. [Безопасность](/ru/security) |
| Релеер | Синхронизировать риск-состояние, фиксировать закрытия, снижать лимит плеча или удалять рынок, ставить на паузу |
| Получатель комиссий протокола | Получать половину премий, подписок и конфискованной прибыли, причитающуюся протоколу |

Исходный код контрактов — в репозитории `EVM`, в `src/funded` и `src/challenge`.
