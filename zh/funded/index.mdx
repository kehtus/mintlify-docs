> 真实的 Hyperliquid 成交。规则和派付写在合约里，不在公司后台。

交易员获得 Hyperliquid 上的链上 funded 账户：深度流动性，没有公司托管登录，激活后没有隐藏条款。成交是真实资本，走真实的 Hyperliquid 订单簿。每一步都可以核验。

与托管式 prop firm 不同，这里的普通利润由交易员和 Builder 按锁定的 `builderPoolBps` 分成。Vault 和协议不拿其中任何一部分。他们赚溢价、订阅和被没收盈余，而不是靠拒绝派付。

<Tip>
合约已经入账的利润不属于公司。公司不能在协议规则之外随意拒绝这笔派付。
</Tip>

## 如何获得账户

由 Builder 开户，或交易员自己调用 `activateFunded`（自费）。Builder 在协议外如何筛选（评估、自己的店铺）是他们的产品，不是协议。

账户绑定交易员的 HyperEVM 地址。交易走 API 钱包。Exchange Proxy 为 Hyperliquid 签名。交易员从不持有该密钥。

| | 赞助 | 自费 |
|---|---|---|
| 谁付 `R + P` | 调用方。他们就是 `record.builder` | 交易员 |
| 本金 `A` | 来自 MainVault | 来自 MainVault |
| 日回撤 | 开 | 关 |
| 时间 | 30 天订阅，可续期 | 预付 1 / 7 / 30 天 |
| 普通利润 | 按 `builderPoolBps` 分成 | 同一套公式，两个桶都给交易员 |

生命周期下限相同。自费没有日下限，盘中路径更宽。

当前 MainVault 名单是唯一市场名单。编辑不会关闭账户。名单外的新开仓会被拒绝。已撤市场上的剩余仓位会被平掉。

```
激活 → Active → 交易
              → 提取利润（可选）
              → 关闭 → 结算 → 领取
```

关闭只有一条路径。克隆快照实际 Core 交易资本 `Q`。MainVault 套用冻结记录，并记入领取账本。
