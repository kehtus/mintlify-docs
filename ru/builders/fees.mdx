## Что выбирает билдер

| Параметр | Коридор | Что делает |
|---|---|---|
| `trader` | любой адрес | Кому открывается счёт. Если это вызывающий, путь self-funded |
| `accountSize` | $10-$20,000 | Принципал `A` |
| `drawdownBps` | 5%-25% | Trailing `D`. Задаёт резерв `R` |
| `builderPoolBps` | 10%-70% | Доля билдера в обычной прибыли |
| `targetProfit` | ≥ 0 | Абсолютный TARGET. `0` выключает |
| `feeBps` | 200 / 400 / 800 | Спонсируемый только **200**. Self-funded выбирает срок |
| `proposedReferrer` | необязательно | Привязывает вызывающего |

Daily drawdown параметром не передаётся. У спонсируемого он есть, у self-funded нет.

`MIN/MAX_ACCOUNT_SIZE` и `MIN/MAX_DRAWDOWN_BPS` админ может сдвинуть через `setRiskConfig`.

## Плата за активацию

```
R = floor(A × D / 10_000)     // резерв билдера
P = ceil(A × F / 10_000)      // премия от A, не от R
плата = R + P
```

Поднять `D` значит положить больше возвращаемого резерва. Премия от этого не растёт.

| Путь | `F` | Срок |
|---|---|---|
| Спонсируемый | 2% | 30 дней, возобновляемая подписка |
| Self-funded T1 | 2% | 1 день предоплата |
| Self-funded T2 | 4% | 7 дней предоплата |
| Self-funded T3 | 8% | 30 дней предоплата |

```
премия протокола = floor(P × 50%)
премия волта     = P − премия протокола
```

Вызывающий платит `R + P` в USDC. MainVault кладёт ровно `A` как принципал.

Пример: `A = $1,000`, `D = 10%`, спонсируемые 2% → `R = $100`, `P = $20`, плата `$120`. Волт и протокол берут по `$10` премии. Резерв `$100`. Аллокация `$1,000`.

## Лимиты аллокации

Депозит в волт для активации не нужен. Режет только сам волт:

| Лимит | Дефолт | Что режет |
|---|---|---|
| Макс. утилизация | 80% NAV | Доля волта в активных счетах |
| Один счёт | 10% NAV, потолок $20k | Один `A` |

При дефолтах активировать нельзя, пока NAV меньше $100. Депозиты ниже этого порога можно.

## Подписка

```
subscriptionFee = ceil_to_1_USDC(A × 1.5%)
```

Сплит 50/50 волт / протокол. Билдер получает 0.

Спонсируемые счета продлеваются из Core equity в последние 3 дня периода, если комиссию можно взять без пробоя полов. Self-funded так не продлевается. Доп. время это `extendRental` (те же тиры, без нового `R`, горизонт сейчас + 30 дней).

## Профит и close

Живой вывод и неконфискующий close идут по `builderPoolBps`. Конфискующий close (`Drawdown`, `TraderRequested`) обнуляет невыведенный `Q − A` и делит этот surplus 40 / 20 / остаток LP. Неиспользованный `R` возвращается `reserveRecipient`.

Admin close сохраняет обычный сплит. Это break-glass, не конфискация.
