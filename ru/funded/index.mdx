`FundedAccount` это изолированный EIP-1167 клон на HyperEVM. MainVault кладёт принципал `A` на Hypercore. Торговля идёт через API-кошелёк. Exchange Proxy подписывает Hyperliquid, сырой ключ трейдеру не выдаётся.

Билдер задаёт условия. Контракты их исполняют.

<Tip>
Правила, сеттлмент и клеймы живут в опубликованных контрактах. Проп-фирма не может переписать пол или отказать в выплате, которую контракт уже начислил.
</Tip>

## Два пути

| | Спонсируемый | Self-funded |
|---|---|---|
| Кто платит `R + P` | Вызывающий. Он же `record.builder` | Трейдер (он же вызывающий) |
| Принципал `A` | Из MainVault | Тоже аллокация из волта |
| Депозит в волт | Не нужен | Не нужен |
| Daily drawdown | Есть | Нет |
| Время | Подписка 30 дней, может продлиться | Предоплата 1 / 7 / 30 дней, без автопродления |
| Обычная прибыль | Сплит по `builderPoolBps` | Те же формулы, оба куска трейдеру |

Self-funded это `activateFunded`, когда вызывающий и есть трейдер. Lifetime-пол тот же, внутри сессии путь шире, потому что дневного пола нет.

Живой список рынков MainVault это единственный список. Правка whitelist счёт не закрывает. Новые входы вне списка отклоняются. Остаток на снятом рынке сворачивается. Остальные рынки остаются торговыми.

## Жизненный цикл

```
активация → Active → торговля
                   → вывод профита (необязательно)
                   → закрытие → сеттлмент → claim
```

Закрытие одно. Клон снимает фактический торговый капитал Core `Q`. MainVault берёт замороженную запись (размер, резерв, билдер, сплит) и начисляет pull-леджер. Коммерческие условия в close никто не подставляет.
