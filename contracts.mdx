The protocol contracts run on HyperEVM; funded accounts trade on HyperCore. The protocol is not open to the public yet. HyperEVM contract amounts use USDC with six decimals.

## Funded accounts

| Contract | What it does |
|---|---|
| `MainVault` (proxy) | Holds the USDC, mints LP shares, funds and settles every funded account. UUPS proxy; the owner can replace the implementation |
| `MainVault` implementation | Vault logic that the owner can replace through a proxy upgrade |
| `FundedAccountFactory` | Clones one `FundedAccount` per activation |
| `FundedAccount` implementation | Logic referenced by the clones created by the factory |
| `Forwarder` | ERC-2771 forwarder for signed requests; the submitting relayer pays transaction gas |
| `ReferralRegistry` | Referral bindings shared by funded accounts and challenges |

## Challenges

| Contract | What it does |
|---|---|
| `ChallengeVault` (proxy) | Sole holder of challenge USDC: purchase locks, outcomes, promotion into a funded account. UUPS proxy |
| `ChallengeVault` implementation | Vault logic that the owner can replace through a proxy upgrade |
| `ChallengeFactory` | Checkout: pricing, fee routing, `buyChallenge` |
| `ChallengePlanRegistry` | Backer plans: immutable once published, can be disabled |

## Roles

| Role | Can |
|---|---|
| Owner | Upgrade both vaults, change parameters and integrations, pause and unpause. A single address today; see [Security](/security) |
| Relayer | Sync risk state, commit closes, lower a leverage cap or remove a market, pause |
| Protocol fee receiver | Receives the protocol half of premiums, subscriptions and forfeited profit |

Contract source is in the `EVM` repository under `src/funded` and `src/challenge`.
