## 你选择什么

| 参数 | 区间 | 作用 |
|---|---|---|
| `trader` | 任意地址 | 克隆所有者。若 `trader` 是调用方，则走自费路径 |
| `accountSize` | $10-$20,000 | 本金 `A` |
| `drawdownBps` | 500–2500（5%–25%） | 追踪回撤参数 `D`，决定准备金 `R` |
| `builderPoolBps` | 1000–7000（10%–70%） | 普通利润中出资方的分成比例 |
| `targetProfit` | ≥ 0 | 以 USDC 计价的目标利润金额；`0` 表示不启用目标 |
| `feeBps` | 200 / 400 / 800 | 出资方路径必须传入 **200**。自费选择期限 |
| `proposedReferrer` | 可选 | 绑定调用方 |

日回撤不是可选参数：出资方账户启用，自费账户不启用。

## 激活时支付的金额

公式中的 `D` 和 `F` 分别对应 `drawdownBps` 和 `feeBps`，以基点（bps）表示：100 bps = 1%。合约中的 `A` 和 `targetProfit` 使用 USDC 最小单位（0.000001 USDC）；下文金额已换算为美元。`floor` 和 `ceil` 按 USDC 最小单位取整。

```
R = floor(A × D / 10_000)     // backer-owned reserve
P = ceil(A × F / 10_000)      // premium, a share of A, not of R
activationCharge = R + P
```

提高 `D` 会增加准备金，但不会提高溢价。准备金用于承担本金损失，只有未消耗的部分会退还。

| 路径 | `F` | 期限 |
|---|---|---|
| 出资方账户 | 200（2%） | 30 天，可续期订阅 |
| 自费 T1 | 200（2%） | 预付 1 天 |
| 自费 T2 | 400（4%） | 预付 7 天 |
| 自费 T3 | 800（8%） | 预付 30 天 |

```
protocolPremium = floor(P × 50%)
vaultPremium    = P − protocolPremium
```

调用方以 USDC 支付 `R + P`。MainVault 存入恰好 `A`。

示例：`A = $1,000`、`D = 1000`（10%）、`F = 200`（2%）时，`R = $100`、`P = $20`，激活时共支付 `$120`。其中 `$100` 为准备金，`$20` 为激活费，由 Vault 与协议各分得 `$10`。MainVault 向账户拨付 `$1,000` 本金。

## 拨付上限

直接激活不要求持有 vault 份额，但受以下拨付上限约束：

| 上限 | 默认 | 含义 |
|---|---|---|
| 最大利用率 | NAV 的 80% | 已拨付给存续账户的本金占 NAV 的比例 |
| 单账户上限 | NAV 的 10%，封顶 $20k | 单个 `A` |

在 NAV 达到启动下限（默认 $100）之前，任何账户都不能激活。低于该值时仍可存款。

## 订阅

```
subscriptionFee = ceil_to_1_USDC(A × 1.5%)
```

按 50/50 分给 vault / 协议。出资方获得 0。

出资方账户在周期最后 3 天通过 checkpoint 用 Core 权益续期：利润必须至少覆盖费用，支付后权益不得低于追踪或日下限。自费账户只能由账户所有者在到期前调用 `extendRental`，选择 200 / 400 / 800 档位购买更多时间，不再缴纳 `R`；新的到期时间最多为当前时间之后 30 天。

## 利润与关闭

账户存续期间的利润提取与非没收性关闭使用 `builderPoolBps`。没收性关闭（`Drawdown`、`TraderRequested`）按实际返回的正利润 `max(Q − A, 0)` 分配：出资方获得 50%，协议获得余数，交易员和 LP 不参与分配。已接受的待处理利润提取不会仅因关闭原因而被没收；未到账款项另受当前关闭超时处理的限制，见[利润与派付](/zh/funded/payouts)。未使用的 `R` 仍退给 `reserveRecipient`。

Admin 关闭保留普通分成。这是紧急出口，不是没收。
