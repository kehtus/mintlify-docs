---
title: "协议规则"
description: "协议在链上强制执行什么，以及 Builder 不能放宽什么"
---

你在允许区间内选择参数。账户上线后，下限、分成和关闭经济不能改。

| 规则 | 取值 |
|---|---|
| 普通利润 | `builderPoolBps` 给 Builder，剩余给交易员。Vault 和协议拿 0 |
| 被没收的盈余 | Builder 40% / 协议 20% / LP 残值 |
| 利润锁定 | 已接受峰值利润的 30%，生命周期与日下限 |
| 提取 | 3 个盈利 checkpoint 日（≥ 0.70%）或利润 ≥ `A` 的 3% |
| Checkpoint | 1 天 |
| 赞助期限 | 30 天订阅 |
| 日回撤 | 赞助开，自费关 |
| 谁可以赞助 | 任何有 `R + P` 的人 |
| 市场 | 当前 MainVault 白名单。编辑不会关闭账户 |

## 追踪下限

```
A = $1,000, D = 10%, accepted peak = $1,200
baseFloor  = $900
profitLock = $60
trailing   = $960
```

日内峰值只有在通过 1% 门槛后才会移动。Checkpoint 接受任何更高的生命周期峰值。已证实的利润领取之后，峰值重置为 `A`。

## 日回撤

不是激活时传入的开关。赞助：开，为 `D` 的一半。自费：关。

同一示例，日初 `$1,000`，日峰值 `$1,200` → 日下限 `$1,010`。有效下限取二者较大值。

## TARGET

`targetProfit` 在链上。零表示关闭。`A + targetProfit` 挡住普通提取。Relayer 写入 `TargetReached`，并保留普通分成。

## 白名单

当前名单就是交易规则。未授权仓位会被平掉。其余仍在名单上的市场可继续交易。Admin 关闭保留普通关闭利润。

筛选、品牌和你在协议外收取什么，都仍归你。激活前可以自己加更严的过滤器。`activateFunded` 之后，由协议保护资本。

funded 账户产生的 Hyperliquid builder-code 费用进入 `protocolFeeReceiver`，不是 Builder。
