## What you choose

| Parameter | Band | Role |
|---|---|---|
| `trader` | any address | Clone owner. If `trader` is the caller, the path is self-funded |
| `accountSize` | $10 – $20,000 | Principal `A` (defaults; admin-bounded) |
| `drawdownBps` | 5% – 25% | Trailing `D`. Sets reserve `R` |
| `builderPoolBps` | 10% – 70% | Ordinary builder share |
| `targetProfit` | ≥ 0 | Absolute TARGET. `0` disables |
| `feeBps` | 200 / 400 / 800 | Sponsored must pass **200**. Self-funded picks the term |
| `proposedReferrer` | optional | Binds the caller |

Daily drawdown is not a parameter. It follows the path: sponsored on, self-funded off.

## Activation charge

```
R = floor(A × D / 10_000)     // builder-owned reserve
P = ceil(A × F / 10_000)      // premium, a share of A, not of R
activationCharge = R + P
```

Raising `D` costs more refundable reserve. It does not raise the premium.

| Path | `F` | Term |
|---|---|---|
| Sponsored | 2% | 30 days, renewing subscription |
| Self-funded T1 | 2% | 1 day prepaid |
| Self-funded T2 | 4% | 7 days prepaid |
| Self-funded T3 | 8% | 30 days prepaid |

```
protocolPremium = floor(P × 50%)
vaultPremium    = P − protocolPremium
```

The caller pays `R + P` in USDC. MainVault deposits exactly `A` as principal.

Example: `A = $1,000`, `D = 10%`, sponsored 2% → `R = $100`, `P = $20`, charge `$120`. Vault and protocol each take `$10` of premium. Builder reserve liability is `$100`. LP allocation is `$1,000`.

## Allocation limits

| Limit | Default | Meaning |
|---|---|---|
| Max utilization | 80% of NAV | Share of vault allocated to active accounts |
| Max single account | 10% of NAV, capped at $20k | One `A` |

No account can activate until NAV reaches the bootstrap floor (`$100` at defaults). Deposits remain available below that.

## Subscription

```
subscriptionFee = ceil_to_1_USDC(A × 1.5%)
```

Split **50/50** vault / protocol. Builder receives **0**.

Sponsored accounts renew from Core equity in the last 3 days of the period if the fee can be paid without breaching floors. Self-funded accounts skip renewal; more time is `extendRental` (same tiers, no extra `R`, max 30 days ahead).

## Profit and close

Live withdrawal and non-forfeiting close use `builderPoolBps`. Forfeiting close (`Drawdown`, `TraderRequested`) zeros the trader’s unwithdrawn `Q − A` and splits that surplus 40 / 20 / LP residual. Unused `R` still returns to the builder.

Admin close keeps the ordinary split. It is a break-glass, not a confiscation.
